# YSeren v0.2.0

这是 YSeren 首个完整的多入口版本。原有 `yseren.exe + yseren.yaml` Headless 用法继续保留，同时新增 Windows Desktop、第二代 Android 媒体源，以及经过原生冒烟验证的 Linux Headless 发行包。

媒体文件始终保留在原设备和原目录中，不上传，也不额外复制。播放继续交给现代浏览器。

## 下载选择

| 使用场景 | 下载文件 |
| --- | --- |
| 普通 Windows 10/11 x64 用户 | `YSeren-v0.2.0-Desktop-Windows-x64-Setup.exe` |
| Windows 用户，不希望安装 | `YSeren-v0.2.0-Desktop-Windows-x64-Portable.zip` |
| Windows 自动化或 YAML 用户 | `YSeren-v0.2.0-Headless-Windows-x64.zip` |
| Linux x64 服务器、NAS、WSL | `YSeren-v0.2.0-Headless-Linux-x64.tar.gz` |
| Linux arm64 设备 | `YSeren-v0.2.0-Headless-Linux-arm64.tar.gz` |
| 把 Android 手机或平板作为媒体源 | `YSeren-v0.2.0-Android.apk` |

下载后请使用 `SHA256SUMS.txt` 校验文件完整性。

## 主要变化

- Windows Desktop 支持选择和管理媒体目录、启停共享、打开/复制局域网地址、托盘、开机启动，以及 YAML 导入导出。
- Android 使用第二代 Compose/Material3 控制界面，通过 SAF 选择目录并以前台服务持续共享。
- Windows Desktop、Headless 与 Android 对齐 `/api/tree`、`/api/status`、`/api/version`、`/playlist.m3u` 和单段 Range 行为。
- Linux Headless x64 完成静态构建、HTTP/Range、权限、符号链接、端口冲突、客户端中断及信号退出冒烟。
- Web Player 保持浏览器播放路线，并移除了与浏览器原生菜单重复的倍速按钮。
- 三端版本统一由 `v0.2.0` tag 注入，所有发布文件由同一次 GitHub Actions 流程构建。

## 兼容性

- 旧版 `yseren.yaml` / `yseren.yml` 可继续直接用于 Headless，也可以由 Windows Desktop 导入。
- Android 正式 APK 使用与 `v0.1.2` 相同的发布签名，并将 `versionCode` 提升至 `2000`。
- `/api/videos` 与旧 Android `/stream/<relative-path>` 路径继续保留兼容。

## 已知边界

- YSeren 没有账号或访问密码，只应在可信局域网中使用。
- Windows 安装包尚未进行商业代码签名，SmartScreen 可能显示“未知发布者”；请从本仓库下载并核对 SHA256。
- Linux Desktop GUI 尚未提供。
- Linux arm64 为静态交叉构建产物，目前没有真实 arm64 设备运行证据。
- YSeren 不转码；浏览器能否播放仍取决于媒体封装和编码支持。

完整使用方式、截图、首次运行和防火墙排障请查看仓库 [README](https://github.com/Seacolour/YSeren#readme)。
