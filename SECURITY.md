# Security Policy

## Supported Versions

YSeren is still in an early open-source stage. Security fixes are currently
applied to the latest code on `main`, and to the most recent GitHub Release once
releases are published.

| Version | Supported |
| ------- | --------- |
| Latest `main` | Yes |
| Latest release | Yes |
| Older releases | Best effort |

## Reporting a Vulnerability

Please do **not** open a public issue for security-sensitive reports.

Preferred process:

1. Use GitHub's private vulnerability reporting for this repository if it is enabled.
2. If private reporting is not available, contact the maintainer through GitHub first and share the details privately.

When reporting, please include:

- A clear description of the issue.
- Steps to reproduce.
- Affected versions or commit hashes.
- Any proof-of-concept or logs that help verify impact.

I will aim to acknowledge the report within a few days and follow up with a fix
or mitigation plan as quickly as possible.
